# commit-guard — ba-00001 (profile README)

This file is the **source of truth** for what may be pushed to this repo. Its
executable mirror is `scripts/commit-guard.sh`, installed as a git `pre-push`
hook by `scripts/install-git-hooks.sh`. When these rules change, update the
script to match.

Enforcement is a git hook, not a checklist: it blocks a bad push regardless of
who or what is pushing — any human, any machine, any AI assistant.

## Identity

- Allowed author **and** committer, on every commit:
  - `ba-00001 <124537281+ba-00001@users.noreply.github.com>`
  - `BRIAN BAZURTO <124537281+ba-00001@users.noreply.github.com>` (matches the
    existing history written through the GitHub web editor)
- Forbidden email, always: `jeanstephane@aloyd.com` (maps to the `buildaloyd`
  account) — and any address that is not the noreply above.
- `ba-00001` is the only account with access. No collaborators, no invitations.
- `GIT_AUTHOR_*` / `GIT_COMMITTER_*` env vars override `git config`. If they are
  set, export them to the identity above before committing.

## Hard rules — any one failing blocks the push

1. `git config user.email` is the ba-00001 noreply address.
2. No AI/tool/bot attribution anywhere in the commit messages being pushed:
   `Co-Authored-By:`, `Generated with`, `Generated by`, `auto-generated`,
   🤖, 🦾, `[bot]`, or a bare mention of `claude` / `anthropic` / `chatgpt` /
   `gpt-` / `copilot` / `llm`.
   The literal path `.claude/` is **not** attribution and must not be flagged —
   the patterns require a non-dot, non-alphanumeric character before the token.
3. Author and committer of every pushed commit match an allowed identity.

## Soft rules — warn, don't block

4. Attribution words appearing in added diff lines. Warn only: this repo's
   README legitimately discusses AI coding agents as a subject, and
   `.claude/`, `agents`, and `claude code` appear as normal content.

## Content allowlist (soft-warn exempt in spirit)

- `README.md` — describes AI-agent work as a technical interest.
- `.claude/**` — this framework.

## What never happens here

- No `--force` / history rewrite on `main`.
- No secrets in the repo. The stats API token lives in Vercel env vars only.
- No `projectguidefordev/` content in this public repo (see `.gitignore`).
